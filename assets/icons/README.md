# FerroDb application icon

Part of one icon family shared with FerroIDE (`ferroide/assets/icons/`), whose glyph is code brackets with a rust slash.
This app's glyph: **database cylinder with a rust lid**.

Shared look: dark "iron" squircle (`#3a3d43 → #1b1c1f`), light gray glyph `#dfe1e5`,
exactly one element in the "rust" gradient `#f59a5b → #c2410c`.

| File | Purpose |
|---|---|
| `ferrodb.svg` | master, 1024×1024 — source for 48 px and up |
| `ferrodb-small.svg` | simplified master (heavier strokes) for 16–32 px |
| `ferrodb-glyph.svg` | 24×24 monochrome glyph (`currentColor`) for in-app use (title bar, About) |
| `ferrodb.png` | 1024×1024 PNG |
| `png/NxN.png` | 16, 24, 32, 48, 64, 128, 256, 512, 1024 |
| `ferrodb.ico` | Windows, 16–256 px |
| `ferrodb.icns` | macOS |

Rasters are generated — edit the SVGs, then run `python assets/icons/generate.py`.
Changes to the shared frame or accent must be mirrored in the sister app.
