# H2

Tabular · SQL (H2 dialect) · access layer **J** (JDBC bridge, H2 JDBC driver) · language intelligence level **B**.

## Requirements

| | |
|---|---|
| Target | H2 2.x in regular mode (the dialect file covers 2.2 / 2.3; compatibility modes are not modelled) |
| Tested | Embedded databases in the JDBC host on Java 17: TCK passed |
| JDBC driver | Downloaded by the driver manager from Maven Central (not bundled): `com.h2database:h2`, versions **2.5.252** (default, newest) or 2.3.232, SHA-256 verified. License: MPL 2.0 or EPL 1.0 |
| Java | Java 17 or newer for the JDBC host. If none is found, downloading the driver also downloads an Eclipse Temurin 21 JRE |
| Network | None for embedded and in-memory databases; TCP port **9092** by default in server mode |

Download the driver from the data source dialog or File → Driver Manager…. The H2 engine runs inside FerroDb's JDBC host process, so the driver version is also the engine version for embedded databases.

## Connecting

Driver id `h2`, family `jdbc`.

| Field | Default | Notes |
|---|---|---|
| Mode (embedded / memory / server) | `embedded` | |
| Database (path or name) | — | **Required.** A file path (embedded), a name (memory) or the database name on the server |
| Host (server mode) | `localhost` | |
| Port (server mode) | `9092` | |
| User | — | |
| Password | — | Keyring |
| URL (overrides the fields above) | — | Any URL the H2 driver accepts |

URLs built from the fields:

| Mode | URL |
|---|---|
| `embedded` | `jdbc:h2:file:{path}` (backslashes become `/`) |
| `memory` | `jdbc:h2:mem:{name};DB_CLOSE_DELAY=-1` |
| `server` | `jdbc:h2:tcp://{host}:{port}/{database}` |

- In memory mode the database lives as long as the JDBC host process.
- The SSH tunnel applies to server mode only (and not when the URL field is used).
- Driver options (`key=value;…`) are passed to the driver as connection properties. The SSL tab has no effect.

## Authentication

| Method | Notes |
|---|---|
| Password | User and password as defined in the database; the only method offered |

## What works

| Area | Support |
|---|---|
| Explorer | Schemas (`information_schema.schemata`, default `PUBLIC`) → tables, views → columns. Introspection through `DatabaseMetaData`: primary and foreign keys, indexes, procedures, functions; view definitions and sequences from `information_schema` |
| Console | Level B: highlighting, statement splitting, schema-aware completion (objects, columns, keywords, built-in functions), syntax diagnostics (generic SQL parser), formatter |
| Results | Arrow streams from the JDBC host |
| Cancel | `Statement.cancel` |
| Schema switch | `SET SCHEMA`; current schema from `SELECT CURRENT_SCHEMA` |
| Editing | Single-table `SELECT` results with a key |
| DDL | Generated from the model (identity, generated columns, `COMMENT ON`, sequences) |
| Transactions | Auto and Manual modes |
| Read-only | `setReadOnly` plus a client-side check |
| Explain | `EXPLAIN` text plan; Explain Analyze uses `EXPLAIN ANALYZE` |
| Export | All export formats. Imports use `INSERT` |

## Limitations

- **DDL commits implicitly**: DDL scripts run statement by statement and cannot be rolled back.
- Triggers are not introspected.
- Explain is shown as text, not in the structured plan views.
- An in-memory database is lost when the JDBC host restarts (for example after a crash).
- Level B: no inspections with quick fixes and no rename refactoring.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `H2: no database given` | Fill Database |
| "Database may be already in use" | An embedded file can be open in one process only. Close the other application, or run an H2 server and use server mode |
| The file cannot be read by the selected driver version | Embedded files are opened by the H2 engine of the downloaded driver; pick the driver version that matches the file in the Driver Manager |
| A new empty database instead of your data | The path was wrong and H2 created a new file; check the path (H2 adds the `.mv.db` extension itself) |
| `driver \`h2\` is not downloaded` | Download it in the dialog or the Driver Manager |
| `driver \`Java runtime ≥ 17 (…)\` is not downloaded` | Install Java 17+ or set `JAVA_HOME` |
